# MCP audit reports

No repository MCP audit run is recorded in this branch at creation. This directory is the designated **index** of future evidence-backed audit findings.

The scheduler should write durable audit records to an authenticated ledger, not unconditionally publish raw findings. A public report may link reviewed, nonsensitive evidence and the audited Git SHA.

Future live tool discovery, endpoint tests or CI checks must have a pre-test GitHub Issue/Discussion **in the repository being tested** and an actual same-thread follow-up. Routine read-only file inspection does not count as a test or confirmation of runtime behavior.
