# Corporate agent organization

The twenty **seats** in Volume III are proposed constitutional offices, not proof of twenty currently deployed Agents. A seat must retain its own ID, versioned charter, service principal, role scope, permissible capabilities, information boundaries and historical lineage even if physically co-located with other offices.

[Read all twenty seat charters](SEATS.md).

## Interoffice autonomy

Each seat may act as an MCP **server** supplying permitted tools/resources and as an MCP **client** consuming others, while the parent MCP gateway presents one company to outside hosts. Incoming authority must be verified independently by the called seat. A common database or host does not remove each office's jurisdiction.

**Source basis:** 02, 18–21, 24–25. Exact registered endpoints, service deployment boundaries and committee quorum are not yet decided.
