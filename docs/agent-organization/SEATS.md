## Boundaries

Seat ID and charter survive occupant turnover. Office-level authority is distinct from database roles, evidentiary roles and model inference. Each proposed office advertises a scoped capability and resource catalog and may call other seats by authenticated MCP client requests. The callee independently checks mission, purpose, principal, scope and version.

**AR** can propose relationships and system improvements but cannot automatically adopt them; **COO** governs operational disposition; **CDO** validates structural integrity but cannot assert semantic truth merely by SQL checks; **CKO** maintains retrieval; **CISO** enforces access; **Audit** must examine independently. **Owner/CEO/Board** boundaries require an approved constitution.

Potential physical mapping (separate Workers vs logical services on fewer hosts) and exact server endpoints are open questions. See [interoffice contract](../../specifications/protocols/constitutional-interoffice.md).
