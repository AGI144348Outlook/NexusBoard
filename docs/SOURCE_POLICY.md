# Source and publication policy

The project's source basis is three uploaded ZIP bundles containing **10 + 7 + 8 = 25 PDFs** dated November 11, 2026. Those PDF bytes and ZIP archives are **not committed**. This repository contains derived summaries, technical specifications and a catalog of filenames, not the complete source content.

## Provenance hierarchy

1. Original numbered architectural-journal source (research inputs).
2. Derived Markdown note identified by source number and exact filename.
3. Cross-source architecture document documenting consensus and conflicts.
4. Independent implementation evidence (commit, deployment, migration, run result) **only if separately obtained**.

Reported prior states of other GitHub/Neon/Cloudflare projects are point-in-time **source claims**; they must not be relabeled as fresh audits. Names such as en.relations or mission.create are proposals until a live contract is inspected.

## Status definitions

**Proposed** = candidate design; **Specified** = reviewable contract; **Implemented** = attributable code/configuration; **Tested** = method executed after published pre-test entry and results linked; **Independently verified** = separate examination. No automatic promotion between states.

## Public information

Do not publish credentials, customer data, private chat excerpts, raw source PDFs, nonpublic architecture, or third-party copyrighted materials without rights review. Sensitive evidence may be represented by an opaque reference or hash rather than copied payload. Retention is subject to legal and user-deletion obligations.

When correcting interpretations, link the earlier version, preserve the historical assertion and add a versioned correction with evidence. See [CONTRIBUTING.md](../CONTRIBUTING.md).
