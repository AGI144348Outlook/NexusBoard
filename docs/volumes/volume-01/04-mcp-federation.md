## Documented architectural substance

One parent corporate gateway can present a unified MCP server externally while internally routing to specialist offices and tools. Tools, resources, prompts and optional MCP App UI are different constructs. Source gives example application calls such as mission.create and operator.dock.

## Important boundary

Application federation is not an MCP-standard 'nested server'; example tool names are proposed, not deployed or standard.
