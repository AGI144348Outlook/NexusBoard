## Documented architectural substance

The System Entity, department and Agent are separate organizational scales. Each Agent has identity, constitutional role, governing protocols, tools/MCP interfaces, persistent state, execution runtime and optional swappable model. Mission M-104 illustrates durable authority, evidence and approval despite operator turnover.

## Important boundary

Do not equate a model, Agent, MCP server, or parent entity. Server-side policy is stronger than natural-language instructions.
