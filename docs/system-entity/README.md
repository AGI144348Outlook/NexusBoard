# Persistent System Entity

A NexusBoard **System Entity** is the durable parent organization with persistent identity, namespaces, constitution, departments, Agent/seat registries, policy versions, access controls, shared mission ledger and audit. It is distinct from an AI model, from a single Agent and from the external MCP endpoint representing it.

## Constitutional hierarchy

Owner authority → System Entity policy → departmental delegations → constitutional office charters → assigned Agents → temporary operator leases. Each delegation can narrow authority but must not expand it. Departments represent jurisdiction, not merely labels; disabled services must not be advertised as active.

## Four nonidentical paths

**Authority** flows from approved governance. **Work** flows from operator/mission dispatch to offices and Agents. **Evidence** flows from source encounters through assessment and review. **Feedback** flows from outcomes into proposals and authorized revisions. These should be rendered separately in diagrams and state logs.
