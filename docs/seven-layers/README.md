# Seven per-Agent architectural components

This seven-component model (Source 01) is orthogonal to the twenty-seat corporate structure (Sources 19–20).

1. **Identity:** stable, nonrecycled Agent ID with provenance and lifecycle.
2. **Role:** constitutional mission, jurisdiction, decisions and accountability.
3. **Protocols:** readable instructions paired with executable permission and budget checks.
4. **Tools/MCP:** interoperable capabilities and local functions, with discovery separate from authority.
5. **State:** durable task pointers, memory items, evidence references and checkpoints.
6. **Runtime:** event handler, deterministic workflow, optional model calls, retries and idle behavior.
7. **Model:** replaceable inference provider; never identity or permission source.

A complete Agent requires application-defined governance and execution. Owning an MCP endpoint or using Cloudflare Agents SDK does **not** create this full architecture automatically.
