# Mashet: A Graphical Interface Language for MCP Systems

**Editorial thesis:** Mashet Glyph Grammar is a proposed graphical interface language for representing, composing, routing, governing, and auditing MCP capabilities across independent systems. This is the textbook's central subject, not merely a supporting chapter.

The original 23 Mashet symbols provide a visual reference vocabulary. The expansion toward 96, Hebrew glyph carriers, and other symbolic families are analyzed as extensions or interoperable layers, not assumed to have identical roles.

## Intended readers
MCP developers, interface designers, AI systems architects, HCI researchers, and practitioners working with evidence-based multi-agent workflows.

## Core scope
1. Glyph identity, legibility, accessibility, Unicode and visual grammar.
2. Formal composition, parsing, typing, error states, and human/machine interpretation.
3. MCP mapping: hosts, clients, servers, tools, resources, prompts, capability discovery, invocation, structured results, transport and authorization.
4. Graphical workflows: pipelines, handoffs, provenance, uncertainty, review, commit boundaries and audit receipts.
5. NexusBoard System Entity / Committees / AR SkillBlock Office evidence cards as an applied design case.
6. Unicorn Estate interoperability gaps as evidence-backed case studies, distinguishing proposals from verified integration.

## Editorial safeguards
MCP is the underlying protocol; Mashet is a proposed interface notation, not an official MCP standard or an automatically executable protocol. Preserve source citations, original reports, historical variants and uncertainty. Do not publish private source or claim experimental validation without independent evidence.

Source reports remain on NexusBoard main in `research/reports/`; this branch contains edited book material. No automatic release, merge, or sale.
