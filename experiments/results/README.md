# Actual experiment results

**No results are recorded here yet.** Never create a PASS record merely because a test plan or diagram exists.

When a test has run **after a published GitHub pre-test thread**, record:

- Pre-test Issue/Discussion URL and date, repository/ref, test ID.
- Actual test environment, method, inputs and commands.
- **Observations:** outputs, logs, metrics, exceptions and failures.
- **Interpretations:** meaning of observations, clearly separated.
- Deviations from the registered method, confounders and limitations.
- Evidence/commit/deployment links, negative results and unrun cases.
- Follow-up commentary added to the **same issue/discussion thread**, with next steps.

Use a separate dated Markdown result file only as an index to the canonical GitHub thread; no result without execution evidence. [Methods](../methods/test-protocol.md).
