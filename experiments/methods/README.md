Prior to testing on **any GitHub repository**, an Issue or Discussion must be published **in that repository** documenting the relevant discussion with Timothy, problem, hypothesis, proposed solution, method, expected observations, and disconfirming observations. Post results to the **same thread**. If the plan cannot be published, **do not test**.
